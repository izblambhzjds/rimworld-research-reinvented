## Overview

Research Reinvented replaces RimWorld's flat technology unlock system with a multi-path tech tree that requires prerequisite technologies and specialist researcher bonuses, adds research decay for unused tech to simulate knowledge atrophy in isolated colonies, introduces breakthrough events for major discoveries, and generates randomized tech tree layouts per game for replayability.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Research Reinvented** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Prerequisite Trees** | Techs require specific predecessors, creating meaningful research paths |
| **Researcher Bonuses** | Pawns with specializations research related fields significantly faster |
| **Knowledge Decay** | Unused technologies gradually atrophy without specialist maintenance |
| **Random Layouts** | Procedural tech tree layout creates unique unlocking paths per save |
